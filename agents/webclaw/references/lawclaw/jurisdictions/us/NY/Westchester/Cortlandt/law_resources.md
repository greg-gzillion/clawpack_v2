## Building Permits
- Code Enforcement Division — (914) 734-1010
- Director: John Schembari | Email: codes@townofcortlandt.com
- Department Page: https://www.townofcortlandtny.gov/cn/webpage.cfm?tpid=2513
- Address: 1 Heady Street, Cortlandt Manor, NY 10567
- Permits Required: New construction, additions/alterations, roofing, siding (sheathing replaced), decks, sheds >100 sq ft, fences >6 ft, HVAC, plumbing, electrical
- No Permit: Sheds <100 sq ft not affixed, re-siding w/o sheathing, patios on grade, pre-1984 solid fuel devices
- All work must comply with Town Zoning Code and NYS Uniform Code
