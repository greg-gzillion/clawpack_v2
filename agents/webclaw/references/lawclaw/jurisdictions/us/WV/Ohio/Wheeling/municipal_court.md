# Wheeling City (Ohio County, WV) Courts

## Wheeling Municipal Court
- Serves: Wheeling City
- Address: 1500 Chapline St, Suite 112, Wheeling, WV 26003 (City Hall)
- Phone: (304) 234-3747
- Municipal Court Clerk: Nicole Harrigan
- Email (Clerk): nharrigan@wheelingwv.gov
- Alternate Email: courtclerk@wheelingwv.gov
- Sessions: Begin at 1:30 PM (check for closures)
- Court System Type: DWI/DUI, Traffic infractions, Exclusive Parking, Ordinance violations
- Jurisdiction: Citations from Wheeling PD, building code regulations, health/safety code
- Payments: Checks payable to "City of Wheeling" with ticket number in memo line
- Website: https://www.wheelingwv.gov/municipal-court
- Note: HAS ACTIVE MUNICIPAL COURT; City Attorney prepares cases for prosecution in criminal, health/safety, and building code sessions as well as state and federal court matters
