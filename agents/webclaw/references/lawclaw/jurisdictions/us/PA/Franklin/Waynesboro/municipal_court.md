## Building Permits
- Office: Zoning & Code Enforcement
- Address: 55 E. Main Street, 2nd Floor, Waynesboro, PA 17268
- Phone: (717) 762-2101 Ext. 230
- Code Enforcement Officer: Matthew Schmidt
- Process:
  1. Obtain a Zoning/Land Use Permit from the Borough
  2. Then obtain a Building Permit from a third-party agency (e.g., PA Municipal Code Alliance)
- Website: https://waynesboropa.gov/zoning-codes/
- Permits Required: Zoning/Land Use, Building (via PMCA), construction, sheds, plumbing, electrical
