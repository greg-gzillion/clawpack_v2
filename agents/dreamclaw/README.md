# DreamClaw — AI Vision & Generation

## What It Does
AI-powered visual concept generation and creative vision prompts.

## Commands

| Command | Description |
|---------|-------------|
| `/dream <description>` | Generate AI vision prompt with style/lighting/composition |
| `/imagine <description>` | Creative visual description |
| `/delegate <agent> <task>` | Send task to any agent |
| `/stats` | Agent statistics |

## Quick Start

/dream cyberpunk city at night with neon reflections
/imagine alien landscape with twin suns

text

- **Context**: WebClaw + DataClaw + Chronicle enrichment
